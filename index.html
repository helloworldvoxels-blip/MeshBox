What is MESHBOX?

MESHBOX is a custom C++ 3D sandbox game where you can spawn objects, arrange blocks, and manipulate elements in real-time. Featuring a nostalgic aesthetic complete with classic primitives and the iconic Utah teapot, it gives you complete freedom to build your own creations.

Key Features:

  • Spawn & Build: Use the green tool to spawn red blocks and construct custom formations.
  • Interactive Tools: Use the red move/select tool to click, drag, and position objects across the map.
  • Retro Aesthetics: Enjoy a clean, nostalgic 3D look inspired by early-2000s development sandbox tools.
